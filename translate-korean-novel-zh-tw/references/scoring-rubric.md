# 十項翻譯評分：等權平均至少 85 分

## 適用範圍與算法

使用者要求下列十項各以 0–100 分評分，等權平均至少 85 分。每個有正文的分節都必須達標，全書連續複核後也要再評一次，不以個別章節的平均代替跨章評估。

完整評分只用於 section 與全書。chunk 保留逐段原文核對、五項實際校對及問題與修正紀錄，不要求十項分數或重複說明。既有 chunk 評分可留存，但不當成整節或全書達標的證據。

平均 = 十項分數總和 ÷ 10。先比較未四捨五入的平均，再決定通過；84.99 不算 85。沒有額外設定「每項都須 85」的門檻，較低項目先列為修訂重點。

分數是代理對目前譯稿的有依據自評，標 `agent_self_assessment`；工具只驗證項目完整、數值有效、證據位置及算術門檻，不宣稱獨立品質認證。不得為了通過填固定高分，或把使用者對初稿的經驗估計直接填成分數。

確認漏譯、人物／主詞誤判、情節矛盾、錯誤專名等問題時，先修正並解決 issue；即使平均超過 85，也不能帶著這些問題交付。

## 十個維度

| key | 項目 | 評分重點 |
|---|---|---|
| `fidelity` | 韓文原意還原 | 語意、否定、條件、數量、先後及內容完整；無漏譯或自行補寫 |
| `naming_consistency` | 人名／稱謂一致性 | 主角與配角的名字、別名、尊稱前後一致；連同地名、技能及境界詞庫核對 |
| `relationships` | 人物關係 | 師承、親疏、上下位、敵我關係及誰對誰說話正確 |
| `plot_continuity` | 劇情連貫性 | 動作與因果相接，位置、傷勢、持有物、伏筆及知識揭露時點吻合 |
| `characterization` | 人物性格 | 台詞、判斷及行動保留原作人物特徵，不讓所有角色同一口吻 |
| `chinese_naturalness` | 中文自然度 | 文法、指代、搭配詞與句序自然，避免翻譯腔與過度修飾 |
| `taiwan_usage` | 台灣中文感 | 台灣繁體中文用語自然，排除不合語境的中國慣用語與簡體字 |
| `literary_style` | 小說文學感 | 保留敘事節奏、氛圍、意象與文體；不以堆砌辭藻提高分數 |
| `dialogue` | 對話自然度 | 你我他她及說話者清楚，語氣、敬語、停頓與對話銜接符合角色 |
| `emotion` | 情緒描寫 | 情緒種類、程度、轉折與克制感對應原文，不淡化也不自行煽情 |

沒有對話或人物互動的段落，按原稿敘事方式是否被妥善保留評估，說明該項在此節的適用情況；不能為了取得分數自行增添對話，也不能無依據給滿分。作者附記依其原有聲音與內容評估，不改寫成故事。

只有全數確認排除的 `preamble` 非故事資料可以 `not_applicable`，不納入文學評分。序章、正文、番外及保留的作者附記不得藉此跳過。

## 分數參考

- 95–100：逐段證據支持很高的忠實度、自然度與一致性，接近無可指認的修訂需求；100 需有足夠依據。
- 90–94：表現穩定，語意與敘事清楚，少數表達仍有可選的改善空間。
- 85–89：已可自然閱讀，能忠實呈現原文，細節或節奏尚有可再斟酌之處。
- 70–84：有可具體指出的生硬、風格或一致性弱點；先改善影響閱讀最大的項目。
- 0–69：存在明顯失真或品質不足。若屬實際誤譯、漏譯或關係錯誤，另外建立 issue 並修正，不能靠平均過關。

分數參考用於同一專案前後校準，不是可由句長、字數或關鍵詞自動推算的量尺。

## 評分資料格式

分節 map 加入 `scorecard`。下面只展示一個維度的結構；實際檔案必須包含表列十個 key，不可省略：

```json
{
  "method": "agent_self_assessment",
  "items": {
    "fidelity": {
      "score": 88,
      "note": "寫明此節實際核對結果、修正及仍可斟酌的地方；範例分數不能直接照填",
      "evidence": ["s0001:p0002", "s0001:p0003"]
    }
  }
}
```

`evidence` 指向該節真實原文區塊 ID；整節評估也可用該節 ID。可在 note 補上譯文行號。全書 `book-review.json` 使用相同十項結構，`evidence` 改填實際抽取作為評分依據的分節 IDs，並結合已完成的全書連續閱讀結果，不只評幾段樣稿。

全數排除的前置文字使用：

```json
{"method":"not_applicable","reason":"本節全數為已核實的來源廣告，沒有小說正文；依對應檔排除"}
```

評分未達平均 85：先從較低項目的證據定位句子，修訂，重新完成受影響的語意／潤色後回查，更新映射及評分，再執行驗收。即使只改評分說明也會使原有指紋收據失效。

## 簡體字與中國慣用語

工具載入 [字詞檢查清單](zh-tw-review-rules.json)，抓取已列的高信心簡體字及常見中國慣用語。這不是完整字典；全書仍需代理做字形與地域語感檢查。

「后」「里」「云」「干」「台」「斗」「范」「岳」等有合法繁體用法或姓名用途的字，不直接當作簡體錯字。中國慣用語也要先理解語意，例如「信息」依場景可改為資訊、消息或情報，不能無腦全域取代。

原作精確書名、引文或使用者指定名稱若確實需要保留被標記字樣，僅能在 map 的 `language_allowances` 明列該句的精確文字、譯文起訖行號、原文區塊證據與保留理由。例外只套用指定行，不准用「原文如此」放行整本；一般正文直接修正。

```json
{"text":"要保留的精確字樣","target_lines":[3,3],"source_ids":["s0001:p0001"],"reason":"填入實際原文或使用者指定名稱的保留依據"}
```

清單、譯文、例外或評分變更後，受影響驗收需重做。最終交付須同時滿足平均 85 分、文字規則及原本的完整性／語意校對要求。
