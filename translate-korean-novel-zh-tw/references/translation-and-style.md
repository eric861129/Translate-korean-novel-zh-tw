# 重譯、語意核對與中文潤色

## 每個翻譯小段的工作順序

1. 每節先用 [prepare-section](resume-and-delivery.md#準備本節資料) 取得原文、詞彙、口吻、文體與前節摘要，保存實際 `context_state`。確認當批與當前小段的來源範圍，讀取該小段完整韓文，先理解場景目的、人物所知、話語意圖與情緒轉折，再落筆。長分節在同一資料包內分頁，不一次塞入上下文。
2. 沿用指紋有效的資料包，另取得前一小段的最新敘事狀態；隱含人物或專名須明列補入。人工版只在定位同段、辨認名稱或研究譯名差異時查看；不要以其中文句子作為新稿骨架。
3. 先依 [主詞與指代核對](#主詞與你我他她) 確認對話及動作的角色，再從韓文撰寫該小段完整繁中初譯，記錄每個來源區塊的去向。依 [分批計畫](source-and-chapters.md) 控制字元數；不把小段草稿冒充完整分節。
4. 原文逐段核對，處理語意錯誤及漏譯，再暫時不看韓文，單獨順讀中文，檢查讀者能否自然理解動作、對話、情緒與轉場。
5. 潤色後重新回查韓文，確認主體、否定、程度、因果與內容都沒改變，才保存校對聲明。

工具回覆出現截斷、`truncated`、省略號代替內文，或只顯示小段開頭／結尾時，未顯示的內容不算讀過。改用 `prepare-section --from-block --through-block` 依既有區塊 ID 分頁；舊流程的 `show` 也保留相同分頁參數。逐頁確認首尾、頁間連續且正文全部可見，再完成語意核對。JSON 已存檔、程式計數正確或來源 ID 全覆蓋，都不能代替實際閱讀；不得由摘要猜補未讀原文後填 `passed`。

只有完成實際檢查後，才把該檢查記為 `passed`。一次產生流暢中文不等於完成三個校對階段。檢查結果及原文 IDs 交給 [自動保存工具](resume-and-delivery.md#自動保存合併與共用閱讀) 產生行號、指紋與進度；不要把翻譯時間花在手算或反覆輸出可重算欄位。完整分節的中文順讀若也實際檢查前節銜接、專名與人物知識，可同時登記分節及該範圍的全書閱讀；原文核對、潤色後回查與全書跨批次判斷各自仍有必要。

每小段完成全部檢查才進入下一小段；完成一個內部工作單位 `b` 即按 [日常保存](resume-and-delivery.md#自動保存合併與共用閱讀) 保存，再續作當前交付批次 `d`。整個 `d` 驗收後才回報當批完成；全書 Goal 或一般全書任務隨即接續下一個 `d`，指定範圍任務則依原範圍收尾。約十批與 Goal 持續執行都不改變逐段校對要求。

## 本書文體設定

首次試譯後在同一進度檔的 `style_profile` 保存本書的 `narrator_voice`、`dialogue_quotes`、`nested_quotes`、`inner_monologue`、`recollection`、`scene_separator` 與特殊版式說明，值以明確文字描述。`narrator_voice` 記錄原作的敘述口吻、正常視角切換及適用範圍，不要求全書固定同一人稱。續譯先沿用這份選擇；既有專案沒有此欄位時，先核對有效譯稿的用法再補齊，不重新隨意選標點與敘述口吻，也不另建文體文件。

## 小段前後文

每次載入當前來源小段、相關詞彙、前一小段的敘事狀態與末尾 1 至 3 個完整段落。前文原文及譯文各先以約 500 至 1,000 字元為閱讀起點；若還不足以確認說話者或因果，再有目的地擴讀並縮小當次新譯量，不以額度為由猜譯。

後文只讀釐清當下句意所需的少量段落，不能以後來才揭露的身分、性別或設定改寫目前視角。上下文標為 `context_only`，不計入新譯字元、逐段覆蓋或合併輸出，避免每批接縫重複一段。

每小段結束保存視角人物、在場角色與說話者、時間地點、事件結果、人物當時已知資訊、未完對話／懸念及新譯名。末尾若有未結束的對話、引言或省略主詞，將已核實的最後說話者→聽話者、引言層級、動作主體及來源 IDs 簡記於既有 `state_after.known_facts`，真正未決者列 `open_threads` 並依問題規則處理；整節需接續的資訊納入 `continuity.jsonl`。新小段開頭逐一比對前文原文，遇到新發話提示或轉場立即重判，不把摘要中的角色固定套到後句。摘要是恢復入口；正式核對仍回讀原文。專名與敘事事實回寫工作資料，不只存在對話歷史。

## 場景理解與語意判定

先判斷這段在故事中的作用：交代資訊、交鋒、試探、隱瞞、反轉、營造不安，或讓讀者暫時誤解。再確認「誰知道什麼、誰相信什麼、讀者此刻知道多少」。角色的猜測、誤會、自我安慰及誇口要保留為角色的看法，不改成旁白確認的事實，也不為讓讀者容易理解而提前揭露答案。

遇到省略、長句或多重轉折時，先還原施事者、承受者、動作、時間、條件、否定、程度與結果。特別保留「推測／確定、傳聞／親見、意圖／已做、能力／意願、請求／命令、反問／提問」的差別。這是理解用的檢查，不要求每句新增一份分析檔。

有兩種合理讀法時，依序回查同場景前後句、人物當時所知、稱呼與語氣，再找同詞在本書的用法；人工版可作交叉參考，不能單憑它定案。影響人物、因果、時間或招式作用而仍無法判定的歧義，留在工作問題紀錄，先處理不受影響的段落；不把自行猜測寫成確定情節。原作刻意保留的模糊則保留，不擅自替作者解釋。

## 忠實度

保留每個動作、感知、推測、情緒轉折、伏筆、場景切換及有效重複。原作刻意遲疑或重述時，不因中文精簡偏好刪掉。

特別核對：

- 韓文省略的主詞、受詞與說話者；不要把動作從甲移給乙。
- 否定、雙重否定、假設、讓步、可能性、尚未與已經。
- 數量、成數、時間、距離、方位、左右、傷勢位置與技能層級。
- 第一／第三人稱與視角切換；序章的「我」不強制延續到第三人稱正文。
- 敬語、反諷、威脅與地位關係；角色裝作客氣不等於真心尊敬。
- 擬聲詞代表的實際動作，及成語、慣用語的整體含義。

可以調整句序，但不能補入未表達的理由。「血腥味讓他愉悅，他正接近線索」不能擅自改成「他循著血腥味追查線索」。

不要把對嘴唇動作的描寫，誤解成對嘴本身施力；須先確認真正受詞是人還是身體部位。遇到武俠語彙也要依上下文判定，不能只逐字音譯。

## 主詞與「你／我／他／她」

韓文常省略主詞、受詞，也未必標明性別。中文是否補主詞，取決於原意及讀者能否辨認；不要求每句補出代名詞。**先從韓文確定角色，再檢查中文讀者會把動作或台詞歸給誰**，不能用已寫出的中文反過來證明自己的判定。

### 先確認角色，再落筆

1. 區分旁白、直接對話、內心、轉述與回憶，確認當下視角及引言層級。視角人物、說話者、動作者可以是不同人。
2. 每輪對話辨認「說話者→聽話者」；每個動作、感受、想法或轉述子句辨認「誰→做／感受／以為什麼→涉及誰」。給予、救援、攻擊、使役或被動句另核對承受者、受益者；身體部位及「自己的」要確認屬於誰。
3. 先查本句明示的人名、代詞、格標記及發話提示，再查同場景前後句、問答內容與動作承接；最後以人物當時所知及關係交叉核對。明示原文優先於慣例；提示可能在台詞後面，需讀完再定案。`은/는` 的話題不直接等於每個動詞的動作者，敬語也不能單獨決定誰說、誰做。
4. 直接引言中的「我／你」按該層的說話者與聽話者定位；轉述改成間接引語時，重新核對人稱。`자기`、`자신`、`당신` 等須辨義及確認回指對象；例如 `당신` 也能敬稱前文提過的人，不能固定替換成「你」。
5. 根據已確定的關係寫中文，核對省略、新增的代名詞，以及拆合句後是否改變主體。敘事中的「他／她」依當時已揭露資訊判定；性別未知時可保留自然省略或使用原文已可辨識的稱謂，不憑名字、聲音印象、人工版或後文揭露指定性別。

禁止用「最近出現的人名」「上一句主詞」「主角通常會這樣做」或固定甲乙輪流發言來直接定案。稱呼可能是呼喚聽者；一個句子也可能包含不同子句主詞。這些線索需和原文關係一併核對。

### 易誤判處與歧義處理

同場景有多個可能指涉人物、未標說話者的對話、省略主客體且動作換人、轉述／嵌套引言、視角／場景切換，以及小段／分節接縫，均須特別核對。有明確依據時可定案，不為理論上任何可能讀法無限擴讀。

- **原文可判定，中文容易誤認**：在必要位置使用已核實的名字或稱謂，或調整句序，讓中文對應相同角色；不額外添加原文沒有的「某人說」、動機或情節。避免整段連續數個「他」承接到不同人物。
- **目前資訊不足，但補讀可能釐清**：依 [小段前後文](#小段前後文) 有目的地擴讀，確認兩個候選讀法的分歧；不能用人工版或「哪句較順」取代原文依據。仍會影響誰說、誰做或誰受影響時，記錄來源 IDs 與待確認關係到 `reviews.jsonl`，受影響小段保留草稿，不填 `referents: passed`。
- **原作本來未指明，或刻意保留模糊**：維持相同資訊範圍；中文可自然省略時不硬補「你／我／他／她」。「對方」「那人」同樣需要語境支持，不能用來掩蓋已改變的角色關係。能忠實保留模糊即記在校對 note，不製造無法解決的問題。

### 定稿反查與簡短證據

初譯逐段核對時建立角色對應；定稿中文順讀時，先不借助腦中的韓文，檢查讀者會認為誰在說、誰在做、誰承受或知道，再回查韓文對應。全部內容照常核對，對高風險句、潤色時補刪主詞或拆合句處特別回查。合併整節後檢查每個小段接縫及本節開頭，不能只看每段內部是否通順。

沿用 `reviews.referents.note` 保存高風險位置的**來源 IDs、角色對應、判定依據及實際修正**。同一段連續相同關係可合併成簡短紀錄，無疑義時記明核對範圍及角色承接；只寫「指代正確」不足以交代檢查內容。不另建角色對照檔、不新增 JSON 欄位、不逐句輸出長篇分析，也不要求額外模型呼叫。

紀錄形狀示例，須換成實際來源與結果：`s0012:p0031～p0033：本輪甲→乙，「我」=甲、「你」=乙，依 p0033 的發話提示判定；中文第二個「他」易誤指乙，已改用甲的既定稱謂並回查。` 發現誤判時，同步檢查其後沿用該身分的台詞、動作及敘事摘要，不只替換單一代名詞或全書搜尋取代。

以下為自造的核對示例，不是固定譯法或任何真實小說的驗收結果：

| 原文／情境 | 核對重點 |
|---|---|
| `민수가 영희에게 말했다. "내가 널 지킬게."` | 說話者是民秀，聽話者是英姬；本句「我」=民秀、「你」=英姬，保護方向不可顛倒。譯名僅供示例。 |
| `"제가 하겠습니다." 영희가 말했다.` | 發話提示在後；這句「我」對應英姬，不能沿用前一位說話者。 |
| `영희는 가방을 메고 문으로 향했다. 민수가 물었다. "어디 가?" "집에 가." 영희가 대답했다.` | 問句省略的「你」及答句省略的「我」都指英姬；依出門動作與回答者核對，不能把回家者改成民秀。 |
| `민수는 영희에게 손을 내밀었다. 영희는 그 손을 잡았다. 그러고는 민수를 끌어올렸다.` | 最後一句英姬承接動作、民秀是被拉起者；省略主詞不能因最近出現民秀的名字而改指民秀。 |
| `철수가 영희에게 말했다. "민수가 나에게 '내가 너를 기다릴게'라고 했어."` | 外層哲秀對英姬說話，內層引用民秀對哲秀的話；內層「我」=民秀、「你」=哲秀。不能把內層「你」指向外層聽者英姬。 |
| 場景只以「蒙面人」稱呼，尚未揭露性別；中文需要補出主體 | 沿用可辨認的稱謂或自然省略，不因後文才揭露的身分先寫「她」。 |

語法查證參考：[國立國語院對 `이/가` 與 `은/는` 的說明](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=310153)、[《韓國語基礎辭典》`당신`](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=30200)。查證用於釐清語法與詞義，人物對應仍以小說當下原文為準。

## 台灣繁中小說語感

使用自然繁中，避免翻譯腔、僵硬指代與不必要的「進行、的樣子、那個存在」。但刪改前要確認這些字沒有承載原作語氣。

武俠、奇幻、現代小說採各自合適的語域。不要一律古文化，也不要讓所有角色都說現代聊天口吻。角色的年齡、地位、性格與親疏要能從台詞辨認。

原文內容區塊是核對單位，不是中文句型模板。先理解完整意思，再依中文的資訊順序組句；可在不改變動作先後、焦點與揭露時機的前提下合併短句或拆開長句，並保留來源對應。動作交鋒保留速度與停頓，思索和鋪陳保留必要延展，不把全書統一成短句，也不把每句都寫成冗長的文學句。

比喻、慣用語、笑點與擬聲先判斷在場景中的作用，再選自然中文。能保留的具體意象盡量保留；直譯難懂時用最少幅度調整，不任意換成含義或文化背景不同的成語、台灣時事梗或網路流行語。原作的時代稱謂、度量與文化資訊若需釐清，查證留在工作資料，正文不自行加註解或換算。

有意義的重複、角色口頭禪及招式反覆呼喊可以形成節奏，不能一律去重。反之，原文沒有的「嘴角勾起一抹」「眸中閃過一絲」等慣用修飾，不因追求小說感反覆補入。擬聲要對應實際聲音與動作，保留強弱和次數，不把普通碰撞渲染成爆炸。

## 人物口吻與對話意圖

在既有人物紀錄中為主要及反覆出場角色保留簡短口吻依據：常用稱呼、你／您選擇、說話長短、直率或含蓄、粗口強度及原文例證。敘述者的語氣、人稱與敘事距離則記在本書 `style_profile`。每條描述都要由已讀內容支持，不預先套「主角霸氣、反派陰冷」等角色模板；偶爾一場情緒爆發不代表永久改變說話方式。

同一角色對師長、部下、敵人或親近者可以有不同說法。敬語可能表達尊重，也可能用來疏遠、譏諷或試探；先辨認關係與當下目的，再選中文稱謂、句尾與語氣，不只逐字對應禮貌程度。前後問答要接得上；敷衍、避答、話說一半及故意答非所問，不能修成完整坦白的回答。

保留台詞的表面說法與潛台詞。角色說反話時，讓中文仍能透過語境讀出反諷，不直接改寫成他心中的真意，也不自行加上「他諷刺地說」或內心解說。同一人連續發言與短動作可自然銜接，換人或視角移動再清楚分段；對話留白服務閱讀，不取代說話者判定。

## 有限潤色

初譯若已忠實且通順，保留原句，以人名、主詞、搭配詞、指代及地域用語的細節修正為主。不要每句換同義詞或刻意修得華麗。「初稿通常已有約 85%」只作工作經驗參考，不填成品質實測值、不降低逐段覆核範圍。

完整分節及全書另依使用者要求執行十項正式評分，平均須達 85 分；chunk 只保留逐段校對、問題及修正紀錄。此門檻與初稿經驗估計不同。詳見 [評分規準](scoring-rubric.md)。文學感與情緒分數評估是否忠實、自然地呈現原作，不為提高分數而加戲或誇飾。

## 台灣用語檢查

將不符合台灣讀者習慣的中國慣用語改為合適用法，按場景處理，避免盲目全域取代。例如現代場景的「視頻」可作「影片」、「出租車」可作「計程車」、「小區」可作「社區」；「信息」依語意作「資訊」「消息」或「情報」，不固定只換一個字。

古代語境中的「消息」「文書」「客棧」、角色刻意使用的地方話或原作特殊設定，不能只因詞彙表命中就改成現代台灣用語。正式名稱與專名依詞庫處理；特定角色的口吻保留。

繁簡字與地域用語分開檢查：文字全部是繁體，也可能仍有不自然的中國慣用語。校對紀錄 `locale` 記錄實際查出的詞、採用改法及需要保留的語境，不以「繁體轉換成功」代替此項。

預設正文對話用「」，對話內的引言用『』；獨立內心獨白可用『』，回憶中的原句可用［］，但須先依語境判斷功能，不能看到『』就當作內心。首次試譯後將本書選擇保存於 `batch-progress.json` 的 `style_profile`，以 [固定 TXT 排版範例](../assets/final-layout-example.txt) 為預設；原作符號本身承載情節或區別不同訊息時，保留必要差異並記錄理由及適用範圍。保留必要的省略號、破折號與停頓，場景分隔採一致樣式。

保留暴力、粗口、恐懼、親密或殘酷情緒在原稿中的強度，不為了「順」而淡化或渲染。所有內容仍遵守宿主適用的安全要求。

人名與設定不套用通用字詞替換；繁體字也有正常異體，不能把異體一律判成錯字。小說正文不插入校稿提醒、查證網址、進度、模型心得或自行新增的說明。

## TXT 閱讀排版

小段稿及整節稿先依以下規則排版，讓對話容易辨認；最終 TXT 再由組裝工具統一行間留白：

- 每個說話者的對話獨立成段，與前後敘述段、下一位說話者的對話之間留 **一個空白行**。同一人連續發言按完整語意成段，不逐句插入空行。
- 與台詞緊密相連的說話提示或短動作可保留在同段，例如 `「等等。」他抬手攔住對方。`；不要在引號邊界硬拆句。敘述中的引文、書名或詞語不因有引號就另起對話段。
- 敘述按自然段落分段，段落之間也留一個空白行；不把每一句敘述拆成一段，也不把原作的場景切換前後文字接成同段。純裝飾的場景分隔符刪除，只保留一個空白行，不換成另一種符號。
- 分節稿的章節標題獨立一行，標題後留一個空白行，標題前不留空行；交付版的換章外框由組裝工具加入，不預先放進小段或分節稿。同一段不依固定字數硬換行，讓閱讀器自行折行；正文不加 Markdown 標記、行號或額外縮排。

上述段落規則用於一般敘事。原作中有意義的詩行、書信署名、碑文、系統訊息或清單保留其結構，必要的換行不合併成普通段落；採用方式記在 `style_profile`，不自行增添版面原本沒有的內容。

完整樣式以 [固定 TXT 排版範例](../assets/final-layout-example.txt) 為準，可直接用文字編輯器開啟查看。範例為自造短文，涵蓋章節／分節、敘述、對話、內心、場景切換、書信、詩行、系統訊息及清單；只參考樣式，不把範例內容或原作沒有的類型加進小說。

### 不同章與同章分節的交界

- **不同章**：交付版依序放「前章最後一段 → 橫線 → 新章標題 → 橫線 → 新章第一段」，相鄰非空白行之間各留一個空白行。橫線固定為 `━━━━━━━━━━━━━━━━`（16 個 `━`），不用空格置中或依裝置寬度拉長。範例的 `第2章 竹林小路` 接 `第3章 山腰的亭子` 示範跨章；不額外加「本章完」或分頁字元。
- **同章不同分節**：原稿有分節號時，保留相同章號、章名及各自分節號，例如範例的 `第1章 雨中的訪客（1）` 接 `第1章 雨中的訪客（2）`。該章首個分節有橫線框，後續分節維持一般標題、前後各一個空白行，不重複加框。原稿沒有分節號就不新增。
- **全書開頭與特殊章節**：第一章也使用相同外框；序章、後記等有正文的獨立特殊分節以其已核定標題加框。全數排除、不輸出文字的前置資料不產生標題或外框。這些裝飾只在最後組裝生成，不能加入 section 的逐段對應。
- **工作單位與場景切換**：`c`、`s` 與交付批次是工作索引，不能拿來新增或重編原作章號；同一分節的小段合併後只保留該分節標題。場景切換只留空白行，不輸出 `★ ★ ★`、`＊＊＊`、`* * *` 或其他替代裝飾。醒目橫線框只用於章節標題。

### 原文版式轉成固定樣式

翻譯及分節定稿時判斷各區塊用途，再依下表統一；原稿本身保持原樣。這些需要理解語意的轉換須在建立 map 與驗收前完成，最終組裝不再猜測或改寫段落。

| 原文版式 | 統一輸出方式 |
|---|---|
| 章號、分節號及裝飾標頭 | 依已核實的原稿編號，使用 `第1章 章名（1）`；沒有分節號便省略括號，序章／後記用核實名稱。不憑排版新增章號或故事標題。 |
| 段首空格、Tab、網頁置中及寬度造成的斷行 | 一般正文靠左、無額外縮排；確認屬同一自然段的版面折行才接回一個實際文字行。不同說話者、自然段及有意義的詩行保持分開，不把每句話都拆成一行。 |
| 沒有空行、連續多個空行或只有空格的行 | 每兩個非空白行之間固定一個空白行；原文以大片留白表達場景切換時，前後文字分開成段並留一個空白行，不另加裝飾。 |
| 各式引號或以破折號標示的對話 | 確認說話者及引言層級後，統一正文對話為 `「……」`、內嵌引言為 `『……』`；每位說話者獨立成段，緊接的說話提示可留同段。不把敘述中的破折號誤當對話。 |
| 星號、橫線、圖案或留白形成的場景分隔 | 已確認只是場景切換的裝飾直接刪除，只留一個空白行，不轉成 `＊＊＊` 或其他符號。符號若是密碼、碑文或劇情線索，保留其內容及差異，不當裝飾刪除。 |
| 書信、詩、碑文、署名或清單 | 保留原有項目、順序、詩行及層次，每個必要的文字行之間一個空白行；不擅加稱謂、日期、編號或「以下為書信」等說明。編號／縮排若表達階層，保留可辨識的階層，不一律攤平成敘述。 |
| 系統視窗、任務或狀態訊息 | 純視窗裝飾框可移除；原有標題使用 `【標題】`，每個原有欄位獨立一行並留一個空白行，欄名與值以 `：` 分隔。沒有標題／欄名就不新增；數值、單位、正負號、等級及有效符號完整保留。 |

只能統一外觀，不抹去原文用版式表達的資訊。無法確認斷行、留白或符號的功能時，先回查原文上下文；仍不確定則保留必要結構，在工作紀錄說明，不盲目合併。既有稿若要調整標題、引號或段落，須回到相應分節重新核對，不直接批次替換最終檔；已確認的獨立場景星號則依下述交付排版規則移除。

排版只調整段落與空白，不增刪情節、台詞或說話提示。小段及分節先完成排版，再計算 map 的 `target_lines` 與檔案指紋；行號以含空白行的實際 TXT 計算，空白行可位於對應區間內，但不另算故事內容。合併小段時核對接縫的空行與段落，避免重複空行或黏段。若修改已驗收的小段或分節檔，須重算行號與指紋並重新驗收。

最終完整版採手機閱讀排版，由 `assemble` 自動執行：

- 依 manifest 順序組合已驗收的 `sections/*.txt`，依相鄰有效分節的原稿章號辨識換章並加上上述外框，不用正文關鍵字、`s` 或批次序號猜測。每兩個非空白行之間固定 **一個空白行**，包含章名橫線、標題、敘述、對話及有意義的詩行／清單。
- 既有連續空行或只有空白字元的行統一收斂，不累加；檔首不留空行，檔尾保留一個換行字元。
- 組裝時移除獨立的三星號裝飾行（`★ ★ ★`、`☆ ☆ ☆`、`* * *`、`＊＊＊`，可含空格），不替換成其他裝飾。正文句內的符號與省略號不刪除；其他裝飾於分節定稿時依上表確認並處理。
- 除上述獨立裝飾行外，保留正文文字、標點、行內空格與先後順序，不拆句、不依手機螢幕寬度硬換行。此處的「行」指 TXT 實際換行，閱讀器自動折行不額外插空白。
- 留白、移除獨立場景星號與換章外框是交付輸出的固定排版轉換；外框是版面裝飾，不是新增原文或翻譯內容。不回寫 `chunks/`、`sections/`、map 或既有驗收收據，map 行號仍指向原分節檔。全書驗收通過後才轉換，組裝讀回核對排版後的完整位元內容，最終 SHA-256 以交付檔為準。不得手改交付 TXT 後沿用舊的最終指紋；文字修訂仍須回到分節重新驗收。

## 潤色後的最後一遍

中文單獨順讀時，先當作沒有看過韓文的讀者：人物在哪裡、誰在說話、動作如何接續，是否能從已寫出的中文理解？台詞是否像這個角色對眼前的人會說的話？若需靠腦中補回韓文才能讀懂，回原文修正表達；若原作故意不交代，就保留懸念，不把缺口補成新情節。

再對照韓文逐段問：發生的事是否相同？誰說／想／知道這件事是否相同？程度、確定性與先後是否相同？有沒有為了順讀刪去停頓、反應或推論？特別回查潤色中新增的主詞、因果詞、情緒詞、成語及拆合句處；自然中文不等於可以增加原文沒有的判斷。

以下是自造的語意檢查示例，不是待套用的固定譯法：

| 初譯保留的意思 | 不應在潤色時改成 | 改變了什麼 |
|---|---|---|
| 他似乎早就知道了。 | 他早就知道了。 | 把推測改成確定事實 |
| 至少還能撐三天。 | 只能再撐三天。 | 把下限改成上限 |
| 他沒有立刻回答。 | 他拒絕回答。 | 補入原文未確認的意圖 |
| 「你可真會挑時候。」在原文明確的反諷情境中 | 直接改成責罵或補上嘲諷解說 | 消除角色說反話的方式與潛台詞 |

先連續讀完整小段，修正指代不明、對話接不上、句式單調和情緒斷裂，並檢查與前小段的接縫。整節小段齊備後再合併、完整順讀該節、回查接縫，確認沒有重複段落或漏接；最後才填整節評分與 `record`。篇幅長時順讀也可分批保存進度，不能把只看接縫當作讀完整節。中文好讀與語意忠實都要滿足。
