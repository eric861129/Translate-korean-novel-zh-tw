# 韓文小說繁中翻譯 SKILL

供 Codex 使用的韓文小說繁體中文翻譯工作流。以韓文原稿核對語意，參考使用者準備的人工初翻版，逐段翻譯、校對、保存進度，最後完成分節與全書驗收並組裝 TXT。

**本 Repo 只提供 SKILL、規則、工具與合成測試。沒有小說原文、人工初翻版、實際譯稿或任何小說的翻譯工作目錄。使用者自行準備有權使用的輸入檔案。**

## 新手安裝

1. 在本頁按 **Code → Download ZIP**，下載後使用 Windows 的「解壓縮全部」。公開 ZIP 不需要登入 GitHub。
2. 開啟解壓後的外層資料夾，找到 `translate-korean-novel-zh-tw`。完整保留其中的 `SKILL.md`、`references/`、`scripts/` 與 `agents/`。
3. 建立自己的工作資料夾，例如 `C:\小說翻譯`，將技能資料夾放到下列位置：

   ```text
   C:\小說翻譯\
   ├─ .agents\
   │  └─ skills\
   │     └─ translate-korean-novel-zh-tw\
   │        ├─ SKILL.md
   │        ├─ agents\
   │        ├─ references\
   │        └─ scripts\
   └─ 我的小說\
      ├─ 韓文原稿.txt
      └─ 人工初翻版.txt
   ```

4. 在 Codex 的桌面 App 中，以 `C:\小說翻譯` 建立本機專案，從該專案開始任務。模型選擇 **GPT-6 Luna**，推理強度設為 **Max**；SKILL 文字不會自動切換 App 設定，實際可用模型以帳號顯示為準。
5. 請 Codex 讀取 [SKILL.md](translate-korean-novel-zh-tw/SKILL.md)，先檢查雙輸入與 Python 3.10 以上執行環境。工具使用標準函式庫，不需另外安裝 Python 套件。
6. 先試譯一個完整分節，確認譯名與風格，再明確要求建立 Goal 並完成提供範圍內的全書翻譯。

可直接貼入 Codex：

```text
請使用本專案的 translate-korean-novel-zh-tw SKILL，
先檢查「我的小說」資料夾的韓文原稿、人工初翻版與執行環境。
確認無誤後建立必要工作檔與約十個交付批次，
只試譯最前面一個有正文的完整原分節，完成校對及分節驗收後停下。
先不要建立全書 Goal。原稿與人工版保持原樣。
若已有 translation-work，核對並沿用，不重新初始化。
```

## 翻譯流程

1. 盤點原文範圍與章節，建立該書自己的 `translation-work`。
2. 將解析結果整理為約 2 MiB 的來源包，按需取得當前分節。
3. 同一個 Session 完成逐段翻譯、指代核對與修訂，累積專名、人物口吻、前情摘要及場景紀錄。
4. 小段完成即保存；完整分節合併後實際順讀，再完成十項自評。各分節與全書的平均門檻為 85 分；漏譯、誤譯和指代錯誤仍須修正。
5. 中斷後核對有效保存紀錄，從最早缺口接續；全書驗收通過後才組裝唯一最終 TXT。

AI 的自評與程式測試不構成獨立翻譯品質保證。語意理解和校對由 Codex 完成，工具負責索引、對應、保存及機械驗證。約十個交付批次不等於十次模型呼叫。

## 檔案與更新

- 本 Repo 不接受小說原文、人工版、譯稿、來源包或 `translation-work`。
- 將自己的小說放在另外的本機工作資料夾，不要加入這個公開 Repo。
- 更新前先暫停與備份。下載新版只更新技能目錄，不覆蓋原稿或翻譯進度。
- 回報問題時附上工具版本、操作與錯誤文字；不要在 Issue 貼整段小說、個人資料或憑證。
- 測試中的短句為合成資料，用來驗證程式，不是隨附小說或可供閱讀的小說文本。
